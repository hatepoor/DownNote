# 低落日记 v0.3.1 · Release 说明

> 附件：`DownNote_0.3.1_x64-setup.exe`（32,236,744 字节 ≈ 30.7 MB；Windows 10/11 64 位）——中文安装向导：可选安装位置、桌面快捷方式，自带卸载器；覆盖安装/卸载都不会动你的日记数据。

## 这是什么

开源、本地运行的单用户情绪陪伴桌面应用：无账号、无自有服务器，日记与心情记录只存在你自己的电脑。

## 安装与首次使用

1. 下载 `DownNote_0.3.1_x64-setup.exe`，双击运行安装向导——选择安装位置、可选桌面快捷方式；不需要安装 Python / Node。从旧版本升级直接覆盖安装即可，日记数据不受影响。
2. 安装完成自动启动；首次启动自动建库——数据目录在 Windows 为 `%APPDATA%\down_note`，日记、图片、配置都在这里，不上传。
3. 点左侧栏「设置」，三页：
   - **模型**：Base URL（OpenAI 兼容，填到 `/v1` 一层）+ API Key + 模型名；温度、思考强度可选（默认 1.1 / low）。未配置模型也能照常写日记（降级模式）。
   - **陪伴**：打开主动陪伴，选档位（**冷淡 / 正常 / 关心**控制它来找你的频率）；同页还有「**日记回应**」开关（默认开启）。
   - **人格**：默认就是「朋友发微信」那套口吻；想让它换个说话样子，打开开关写下你自己的 `soul.md`（只存本机，上限 6000 字），保存后下一条消息即生效。

## v0.3.1 更新（相对 v0.3.0）

这一版只修两件事，都是「它该懂你的时候没懂」。

**它会分「气」和「难过」了（修复）**

- 以前不管你是生气还是难过，它都先陪你吐槽。吐槽接得住「气」，接不住「难过」——你难过时它还在骂第三方，等于把你的感受推回去。
- 现在它先判断这一句是「气」还是「难过」：气就站你这边一起骂事情；难过就收起吐槽，认真接住。又气又难过时，先接住难过，再陪骂一句。
- 难过时不再空泛地说「我懂你的感受」，而是接住你话里最重的那句具体内容；不再每句都以问题结尾，也不再问「你现在感觉怎么样」这类盘问。
- 你直接问「我该怎么办」时，它会真的给一点实在的东西——一个方向、一个动作或一句判断，不再用「先别想了」打太极。
- 禁掉了「我懂你」「我也有过」「我在这儿听着」这类套话，也不会再编造自己的经历。
- 开场白同步收紧：不再复述系统给的心情摘要，也不再文艺腔。

**「聊聊」之后它真的知道聊了什么（修复）**

- 以前点完「聊聊」，那句话只出现在界面上，没有进模型的上下文——你追问「你摸到什么」，它会一脸茫然。
- 现在转移的留言会同时写进会话上下文，下一轮它记得这句话，可以顺着聊。
- 同一次对话里点第二个「聊聊」时，界面会刷新并滚到新留言，不再毫无反应。
- 已经转移过的旧留言，再点一次「聊聊」会自动补进上下文，不需要重新写日记。

## 兼容性与数据

- 版本号从 0.3.0 → 0.3.1，覆盖安装即可，**不需要卸载旧版**，日记、图片、长期记忆与设置全部保留。
- 没有数据库结构变更，没有迁移步骤。
- 自定义人格的行为不变：开启后仍然整段替换默认说话风格；这次的情绪分型只作用于默认人格。

## 注意事项

- **关窗口 = 收进托盘**：进程继续在后台；要完全退出用托盘菜单的「退出」。
- **主动陪伴 / 日记回应都需要配置模型**：未配置（或模型调用失败）时它们自动跳过，不会打扰你；降级模式下记录功能完整可用。
- **Windows 10**：若窗口空白，安装一次微软的 WebView2 Runtime（免费，官网下载）；Windows 11 自带。
- **SmartScreen**：未做代码签名，首次运行可能提示"已保护你的电脑"——点「更多信息」→「仍要运行」。
- 程序运行期间占用本机一个随机高端口（仅 127.0.0.1 回环）。
