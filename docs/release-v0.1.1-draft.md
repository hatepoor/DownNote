# 低落日记 v0.1.1 · Release 说明（草稿）

> 附件：`DownNote_0.1.1_x64-setup.exe`（约 21MB；Windows 10/11 64 位）——中文安装向导：可选安装位置、桌面快捷方式，自带卸载器；卸载/重装都不会动你的日记数据。

## 这是什么

开源、本地运行的单用户情绪陪伴桌面应用：无账号、无自有服务器，日记与心情记录只存在你自己的电脑。

## 安装与首次使用

1. 下载 `DownNote_0.1.1_x64-setup.exe`，双击运行安装向导——选择安装位置、可选桌面快捷方式；不需要安装 Python / Node。
2. 安装完成自动启动；首次启动自动建库——数据目录在 Windows 为 `%APPDATA%\down_note`，日记、图片、配置都在这里，不上传。
3. 点左侧栏「设置」配置模型：Base URL（OpenAI 兼容，填到 `/v1` 一层）+ API Key + 模型名；温度、思考强度可选（默认 1.1 / low）。
4. 未配置模型也能照常写日记（降级模式）；配置保存后分析与对话自动恢复。

## v0.1.1 亮点（相对 v0.1.0）

- **桌面壳升级为 Tauri 2**：无边框自绘标题栏（随日/夜主题同色）、启动不闪白（后端就绪才显示窗口）、单实例防双开、安装包更小（31MB → 21MB）
- **唤醒更顺滑**：未唤醒时在输入框打了字再点「新的唤醒」，打完招呼会自动把那句话发出去
- 修复窗口标题栏不随主题的问题

## 功能一览

- 记录（文字 + 图片）→ 后台分析产出心情记录 → 唤醒对话（LangGraph 多智能体）
- 危机应对：关键词初筛 + 模型复判，姿态是共情与提供求助资源，不评判、不中断
- 跨零点自动把一天整合成一篇日记，模型分析日心情并沉淀长期记忆
- 历史按天浏览（过去的日记锁定不可改）、夜间主题、Markdown 渲染、可拖拽分栏

## 注意事项

- **Windows 10**：若窗口空白，安装一次微软的 WebView2 Runtime（免费，官网下载）；Windows 11 自带。
- **SmartScreen**：未做代码签名，首次运行可能提示"已保护你的电脑"——点「更多信息」→「仍要运行」。
- 程序运行期间占用本机一个随机高端口（仅 127.0.0.1 回环）；关窗口即完全退出。
- 本版本不含：定时关怀、信号触发、人格模板、回顾可视化、设置界面（后续版本）。
