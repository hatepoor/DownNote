# 低落日记 v0.2.0 · Release 说明

> 附件：`DownNote_0.2.0_x64-setup.exe`（约 31 MB；Windows 10/11 64 位）——中文安装向导：可选安装位置、桌面快捷方式，自带卸载器；覆盖安装/卸载都不会动你的日记数据。

## 这是什么

开源、本地运行的单用户情绪陪伴桌面应用：无账号、无自有服务器，日记与心情记录只存在你自己的电脑。

## 安装与首次使用

1. 下载 `DownNote_0.2.0_x64-setup.exe`，双击运行安装向导——选择安装位置、可选桌面快捷方式；不需要安装 Python / Node。从旧版本升级直接覆盖安装即可，日记数据不受影响。
2. 安装完成自动启动；首次启动自动建库——数据目录在 Windows 为 `%APPDATA%\down_note`，日记、图片、配置都在这里，不上传。
3. 点左侧栏「设置」，现在是三页：
   - **模型**：Base URL（OpenAI 兼容，填到 `/v1` 一层）+ API Key + 模型名；温度、思考强度可选（默认 1.1 / low）。未配置模型也能照常写日记（降级模式）。
   - **陪伴**：打开主动陪伴，选档位（**冷淡 / 正常 / 关心**控制它来找你的频率）。
   - **人格**：默认就是「朋友发微信」那套口吻；想让它换个说话样子，打开开关写下你自己的 `soul.md`（只存本机），保存后下一条消息即生效。

## v0.2.0 更新（相对 v0.1.2）

**主动陪伴（新）**

- 可选开启、**默认关闭**；关闭时和以前完全一样——你开口，它才回话。
- 开启后它像朋友一样，在一天里自己找时机开口，说的是你日记与记忆里的事：比如"简历上那个邮箱后来改过来没？"
- 三档频率：冷淡（每 4~6 小时一次）/ 正常（每 2~3 小时）/ 关心（每 1~2 小时）。
- 分寸：深夜（22:30–09:00）不开口；你正在写日记或聊天时让路；你不回它不会追着说，连着几次没回应它就安静下来，第二天再恢复。
- 说的话接在你最近那次对话里，不另起一堆新窗口。

**人格模板（新）**

- 默认人格就是原来的口吻，一行代码都没变；新增的是**你自定义**：设置 → 人格 → 写一段话（如"你是一个话不多的朋友，句子很短，偶尔毒舌"）。
- 内容存在本机 `soul.md`，改完**下一条消息即生效**；可随时关掉回到默认。危机时刻的处理姿态不受自定义影响。

**托盘常驻与系统通知（新）**

- 关窗口不再退出应用，而是收进托盘（进程继续跑，它才能主动陪你）；要完全退出：托盘图标右键 →「退出」。
- 托盘菜单：打开主界面 / 开机自启（默认关闭）/ 退出。
- 它主动开口时若窗口不在前台，会发一条系统通知；点通知回到那条会话。

**会话删除（新）**

- 对话 →「历史会话」→ 每条后面有删除入口，就地二次确认。
- 删掉的是这一次对话本身（消息 + 会话 + 模型侧的这段上下文，物理删除、不可恢复）；**长期记忆不受影响**。

**设置**

- 设置从单一对话框整理为侧边栏三页（模型 / 陪伴 / 人格）。

## 功能一览

- 记录（文字 + 图片）→ 后台分析产出心情记录 → 唤醒对话（LangGraph 多智能体）
- 主动陪伴：可选开启、三档频率、像朋友一样自己找时机开口
- 人格模板：默认口吻 + 你自定义的 `soul.md`
- 危机应对：关键词初筛 + 模型复判，姿态是共情与提供求助资源，不评判、不中断
- 跨零点自动把一天整合成一篇日记，模型分析日心情并沉淀长期记忆
- 长期记忆完全透明：可查看、可编辑、可删除
- 历史按天浏览（过去的日记锁定不可改）、夜间主题、Markdown 渲染、可拖拽分栏
- 托盘常驻 + 系统通知 + 开机自启；单次对话可删

## 注意事项

- **关窗口 = 收进托盘**（本版行为变化）：进程继续在后台；要完全退出用托盘菜单的「退出」。
- **主动陪伴需要配置模型**：未配置（或模型调用失败）时它自动暂停，不会打扰你；降级模式下记录功能完整可用。
- **Windows 10**：若窗口空白，安装一次微软的 WebView2 Runtime（免费，官网下载）；Windows 11 自带。
- **SmartScreen**：未做代码签名，首次运行可能提示"已保护你的电脑"——点「更多信息」→「仍要运行」。
- 程序运行期间占用本机一个随机高端口（仅 127.0.0.1 回环）。
- 本版本不含：信号触发（连续低落/强度突变触发的关怀）、回顾可视化、密钥加密存储；也不做"清空全部会话"与"删会话连带删长期记忆"。
