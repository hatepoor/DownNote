# 可插拔 LLM 接口

不同用户对模型的能力、预算与隐私权衡各不相同，内置密钥则带来滥用与成本问题。因此决定对外只暴露 OpenAI 兼容协议（Base URL + API Key + 模型名三件套），用户自备模型服务——云端各家 API 与本地 Ollama 均提供兼容端点，一个协议通吃；端点背后可以是裸模型，也可以是带人设与工具的 agent 服务，对协议而言无差别，我们的提示词照常作为消息下发，远端如何采纳由其自行决定。配置即换，历史心情记录与性格画像保留。日记原文直发用户所配模型服务、不做脱敏，隐私权衡由用户自己掌握。代价是首次使用有配置门槛，且不承诺非 OpenAI 协议的原生适配。
