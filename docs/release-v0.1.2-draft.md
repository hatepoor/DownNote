# 低落日记 v0.1.2 · Release 说明

> 附件：`DownNote_0.1.2_x64-setup.exe`（约 30MB；Windows 10/11 64 位）——中文安装向导：可选安装位置、桌面快捷方式，自带卸载器；覆盖安装/卸载都不会动你的日记数据。

## 这是什么

开源、本地运行的单用户情绪陪伴桌面应用：无账号、无自有服务器，日记与心情记录只存在你自己的电脑。

## 安装与首次使用

1. 下载 `DownNote_0.1.2_x64-setup.exe`，双击运行安装向导——选择安装位置、可选桌面快捷方式；不需要安装 Python / Node。从旧版本升级直接覆盖安装即可，日记数据不受影响。
2. 安装完成自动启动；首次启动自动建库——数据目录在 Windows 为 `%APPDATA%\down_note`，日记、图片、配置都在这里，不上传。第一次打开会有一段三步引导（写记录 → 配模型 → 唤醒对话），可以跳过。
3. 点左侧栏「设置」配置模型：Base URL（OpenAI 兼容，填到 `/v1` 一层）+ API Key + 模型名；温度、思考强度可选（默认 1.1 / low）。
4. 未配置模型也能照常写日记（降级模式）；配置保存后分析与对话自动恢复。

## v0.1.2 更新（相对 v0.1.1）

**修复**

- 对话里说「记一下」，现在真的会写进长期记忆（之前只会口头答应）。
- 心情记录生成明显变快：这种简单的提炼不再先"想一大段"，长日记从 2 秒多降到 1 秒以内。
- 心情记录若生成失败，不再一直转圈：这一条会显示「分析失败」，点旁边的「刷新」即可重试。
- 心情分类更细：标签从 14 个扩到 34 个并按八族归档，且区分了「焦虑 / 不安」「委屈 / 难过」「疲惫 / 无力」「内疚 / 自责 / 羞耻」这类相近感受。

**体验**

- 陪伴对话的语气重写了——像朋友发微信，不再是「理解你的感受、建议你可以…」那种客服腔。
- 日记条目有了悬停反馈：鼠标划过会沉一下底色、左缘亮起一道朱砂。
- 工作台与记忆页之间加了交叉淡化，切换不再生硬。
- 标题栏去掉了重复的小「低」徽标，只留「低落日记」。
- 首次打开有三步引导（写记录 → 配模型 → 唤醒对话），老用户覆盖升级不会弹。

## 功能一览

- 记录（文字 + 图片）→ 后台分析产出心情记录 → 唤醒对话（LangGraph 多智能体）
- 危机应对：关键词初筛 + 模型复判，姿态是共情与提供求助资源，不评判、不中断
- 跨零点自动把一天整合成一篇日记，模型分析日心情并沉淀长期记忆
- 历史按天浏览（过去的日记锁定不可改）、夜间主题、Markdown 渲染、可拖拽分栏

## 注意事项

- **Windows 10**：若窗口空白，安装一次微软的 WebView2 Runtime（免费，官网下载）；Windows 11 自带。
- **SmartScreen**：未做代码签名，首次运行可能提示"已保护你的电脑"——点「更多信息」→「仍要运行」。
- 程序运行期间占用本机一个随机高端口（仅 127.0.0.1 回环）；关窗口即完全退出。
- 本版本不含：定时关怀、信号触发、人格模板、回顾可视化；也还没有完整的设置界面（当前仅有模型配置对话框）。
