# 低落日记 v0.3.0 · Release 说明

> 附件：`DownNote_0.3.0_x64-setup.exe`（32,237,483 字节 ≈ 30.7 MB；Windows 10/11 64 位）——中文安装向导：可选安装位置、桌面快捷方式，自带卸载器；覆盖安装/卸载都不会动你的日记数据。

## 这是什么

开源、本地运行的单用户情绪陪伴桌面应用：无账号、无自有服务器，日记与心情记录只存在你自己的电脑。

## 安装与首次使用

1. 下载 `DownNote_0.3.0_x64-setup.exe`，双击运行安装向导——选择安装位置、可选桌面快捷方式；不需要安装 Python / Node。从旧版本升级直接覆盖安装即可，日记数据不受影响。
2. 安装完成自动启动；首次启动自动建库——数据目录在 Windows 为 `%APPDATA%\down_note`，日记、图片、配置都在这里，不上传。
3. 点左侧栏「设置」，三页：
   - **模型**：Base URL（OpenAI 兼容，填到 `/v1` 一层）+ API Key + 模型名；温度、思考强度可选（默认 1.1 / low）。未配置模型也能照常写日记（降级模式）。
   - **陪伴**：打开主动陪伴，选档位（**冷淡 / 正常 / 关心**控制它来找你的频率）；同页还有「**日记回应**」开关（默认开启）。
   - **人格**：默认就是「朋友发微信」那套口吻；想让它换个说话样子，打开开关写下你自己的 `soul.md`（只存本机，上限 6000 字），保存后下一条消息即生效。

## v0.3.0 更新（相对 v0.2.0）

这一版的基调是**陪伴感深化**：从「按频率开口」变成「它真的有在读你写的东西」。

**日记回应（新）**

- 每写完一条日记，心情分析完成后，它会在条目下方留一两句——像朋友在朋友圈下面认真评论那样。
- 有情绪就回应，不挑正负：低落认真接住、平静简短打个招呼、开心跟着一起开心。不会只在难过时才搭理你。
- 它是对**这一篇**的留言：不弹系统通知、不进会话列表，安安静静待在那条日记下面。
- 想接着聊，点回应尾巴上的「**聊聊 →**」——这句话会原样进到最近那次对话里，你可以顺着说下去；重复点不会重复落话。
- 独立开关（设置 → 陪伴页），**默认开启**；关掉后新写的日记不再生成回应，已经留下的还在。
- 回应只从新日记开始，历史条目不会补——这是有意的，不想让你翻旧账时突然冒出一堆"事后评论"。

**信号触发（新）**

- 以前它按频率开口；现在**连续两天低落、或情绪强度突然升高**时，它不再等频率轮到，而是这一轮就开口。
- 开口内容带着对你这几天的了解，像朋友察觉到「你这两天好像不太对劲」——不点破、不开诊断腔、不下判断。
- 分寸完全照旧：时间窗 09:00–22:30、计入当日上限、你正在写日记或聊天时让路、连着几次没回应就安静下来；应用刚启动的十分钟内不会开口。
- 触发后 48 小时内同一类信号不重复打扰；连续低落的记录中断就重新计数。
- 它随主动陪伴开关生效（关掉主动陪伴，它就跟以前一样完全安静），没有单独的开关。

**记忆可以按日期找了（修复）**

- 以前你说「把 10 月 6 号记的那条记忆删了」，它只能反问"记忆里没有标着日期的条目"；现在它会自己按记录日期对号入座。
- 顺带重申一条铁规矩：**日记落库后不可删**（过去的日记也锁定不可改）。要管理历史内容，走长期记忆——那里查看、编辑、删除都齐全。

**自定义人格放宽（调整）**

- 人格内容上限从 2000 字放宽到 **6000 字**。
- 修掉一个开关关不掉的毛病：以前点「关闭」自定义人格后，这个"关"存不下去，下次进设置页又变回开启。现在开关改动即时生效。

## 功能一览

- 记录（文字 + 图片）→ 后台分析产出心情记录 → 唤醒对话（LangGraph 多智能体）
- 日记回应：每篇日记下方的一两句留言，可「聊聊」跳进会话接着聊
- 主动陪伴：可选开启、三档频率、像朋友一样自己找时机开口
- 信号触发：连续低落 / 情绪骤升时提前开口，内容针对这几天
- 人格模板：默认口吻 + 你自定义的 `soul.md`（上限 6000 字）
- 危机应对：关键词初筛 + 模型复判，姿态是共情与提供求助资源，不评判、不中断
- 跨零点自动把一天整合成一篇日记，模型分析日心情并沉淀长期记忆
- 长期记忆完全透明：可查看、可编辑、可删除，也能按日期定位
- 历史按天浏览（过去的日记锁定不可改）、夜间主题、Markdown 渲染、可拖拽分栏
- 托盘常驻 + 系统通知 + 开机自启；单次对话可删

## 注意事项

- **关窗口 = 收进托盘**：进程继续在后台；要完全退出用托盘菜单的「退出」。
- **主动陪伴 / 日记回应都需要配置模型**：未配置（或模型调用失败）时它们自动跳过，不会打扰你；降级模式下记录功能完整可用。
- **升级不会回填历史回应**：v0.3.0 之前写的日记，条目下方不会有回应；从新写的日记开始有。
- **Windows 10**：若窗口空白，安装一次微软的 WebView2 Runtime（免费，官网下载）；Windows 11 自带。
- **SmartScreen**：未做代码签名，首次运行可能提示"已保护你的电脑"——点「更多信息」→「仍要运行」。
- 程序运行期间占用本机一个随机高端口（仅 127.0.0.1 回环）。
- 本版本不含：回顾可视化、密钥加密存储（原计划的「回望与完善」顺延到后续版本）；主动跟进（结构化话题采集）与周期回顾也不在本版。
