# 03 · 布局与页面

窗口基准 1280×800（最小 1024×680）。整体骨架 = **左侧窄栏 + 单屏陪伴工作台**：当天日记面板（左）与对话面板（右）常驻同屏，历史日记经窄栏抽屉查看。降级横幅条件渲染于内容区顶部。

> 设计意图：写日记的手永远在左边，陪伴的它永远在右边——「记录永远第一」与「Agent 为魂」在同一屏同时成立；历史内容按需查看，不占用日常视野。

## 1. App 骨架

```
┌──────┬──────────────────────────────────────────┐
│      │ ┌──────────────────────────────────────┐ │
│  窄  │ │ 降级横幅（仅降级态，条件渲染）           │ │
│  栏  │ ├────────────────┬─────────────────────┤ │
│ ◉标记 │ │ 当天日记面板     │ 对话面板              │ │
│ [历史]│ │ 今天 · 10月5日   │ 对话 [历史会话][新的唤醒]│ │
│      │ │ ┌────────────┐ │ ┌─────────────────┐ │ │
│      │ │ │ 编辑器（今天）│ │ │ 消息流            │ │ │
│      │ │ └────────────┘ │ │ Agent 气泡 / 用户  │ │ │
│      │ │ [＋贴图][记录今天]│ │ [求助资源卡](危机) │ │ │
│      │ │ 今天已写         │ ├─────────────────┤ │ │
│      │ │ [条目卡+心情记录] │ │ [输入框]    [发送] │ │ │
│ [设置]│ └────────────────┴─────────────────────┘ │
└──────┴──────────────────────────────────────────┘
```

窄栏（NavRail）规格：

- 宽 64px，通高，底色 --bg-inset（比内容区深半档），右边线 1px --hairline。
- 顶部 28px 处放**品牌印章**（满饱和朱砂 `--accent` 实心方块 34×34、圆角 2px，纸白宋体 600 单字「低」，19px）。它是全站唯一实色块——品牌符号以此为准，不再另做图形记号。
- 「历史」入口：书本图标 + 11px 标签，弱化态；点击从左侧滑出历史日记抽屉（见 §4）。
- 底部「设置」入口：齿轮图标 + 11px 标签，弱化态；点击打开模型配置弹窗。完整设置界面仍属 v0.3.0，本期设置按钮仅承载模型配置。
- 悬停/激活态：图标与文字转 --accent，背景 --accent-soft、圆角 12。
- 窄栏不承担降级状态显示——降级统一走横幅。

## 2. 当天日记面板（左栏，约 460px）

- 面板头：「今天」（宋体 16）+ 右侧日期「10月5日 周一」（--fs-caption --ink-3）。
- 编辑器：无工具栏纯 textarea（--fs-entry、行高 1.7、--bg-surface、圆角 lg、1px --hairline-strong，聚焦 2px --accent）；最小高 200px，随内容增高（上限约视口 45%，超出滚动）。
- 贴图：编辑器下方一行——「＋贴图」ghost 按钮（仅支持 1 张，已贴则隐藏入口）；预览 72px 圆角 md + 右上角移除 ×；类型 jpg/png（前端同步限制，后端校验）。
- 提交按钮「记录今天」：--accent 药丸，编辑器区右下；空内容 disabled；提交后清空编辑器与预览。
- 「今天已写」区：当日已提交条目的紧凑卡片列表（时间倒序）——卡片 = 时间 + 正文（最多 3 行截断）+ 心情记录行（chips + 强度点 + 摘要）+ 照顾标记；分析中显示「心情记录生成中…」；**降级模式下心情行不渲染**。无条目时不显示该区，编辑器占位即空态。
- 跨天语义：日期变更后「今天已写」自动清空，昨日条目归入历史抽屉。

## 3. 对话面板（右栏，自适应）

- 面板头 48px：「对话」（宋体 16）+ 右侧「历史会话」ghost 按钮 +「新的唤醒」描边药丸；降级模式下两按钮 disabled（横幅已说明，面板内不另提示）。
- 消息流：填充剩余高度、独立滚动；Agent 气泡靠左（--bg-surface、圆角 xl、1px --hairline、2 层阴影，最大宽 85%），用户气泡靠右（--accent-soft、圆角 xl、无边，最大宽 85%）。
- 唤醒注脚（WakeNote）：新会话 Agent 首条气泡上方一行 --fs-caption「它刚翻过你近几天的日记」；无任何条目时不显示。
- 流式：Agent 气泡内容流式追加，末尾 ▍ 光标（800ms 呼吸），完成后光标消失。
- 危机态：Agent 回复 = 共情正文（正常流式）+ 正文后内嵌求助资源卡（HotlineCard，见 04）。
- 输入区：底部 72px 通栏；输入框圆角 lg、--bg-surface、1px --hairline-strong，1-5 行自适应；Enter 发送 / Shift+Enter 换行；发送按钮「发送」--accent 药丸。降级模式输入区整体替换为一行平静说明 + 「去配置」链接按钮（见 05）。
- 会话历史：右侧滑出抽屉 320px（3 层阴影），列表项 = 日期 + 首条用户消息一行摘要；点击载入该会话继续对话；当前会话高亮 --accent-soft。
- 空会话态：无任何会话时消息列区仅显示居中引导语（见 05），Agent 开场随即流式抵达。

## 4. 历史日记抽屉（DiaryHistoryDrawer）

- 触发：窄栏「历史」入口；抽屉从左侧滑出，宽 340px、通高（3 层阴影），覆盖在当天日记面板之上，窄栏保持可见；抽屉右侧内容区覆盖轻遮罩，点击遮罩 / × / 再次点「历史」关闭。
- 头部：「历史日记」（宋体 16）+ 关闭 ×（右上角）。
- 内容：完整时间线（卡片样式）——卡头相对日期时间 + 照顾标记；正文最多 4 行截断（渐隐遮罩），点击展开/收起；配图缩略 72px 点击进 lightbox；心情记录行（chips + 强度点 + 摘要）；分析中态；**降级模式下心情行不渲染**。
- 空态：居中一句宋体引导（见 05），不配插画。
- 分页：滚动到底加载更早（limit/offset），页脚仅一行加载文字。

## 5. 全局组件层

- **降级横幅（DegradedBanner）**：内容区顶部通栏、高 40px、--banner-bg、文字 --banner-ink（--fs-body）；右侧「配置模型」link 按钮；出现/消失 200ms 滑动；完整模式下不占位。
- **模型配置弹窗（ModelConfigDialog）**：480px 居中卡片（圆角 xl、4 层阴影 + 遮罩 rgba(46,42,36,.32)）；标题「配置模型」（宋体）+ 三字段 + 说明行 + [取消][保存]；API Key 保存后回显掩码（如 `sk-****abcd`）。入口两处：降级横幅「配置模型」、窄栏底部「设置」按钮。
- **图片查看（ImageLightbox）**：遮罩 + 原图居中（4 层阴影），点击遮罩关闭。
