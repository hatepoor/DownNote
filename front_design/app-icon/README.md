# 应用图标

低落日记的应用图标：**满饱和朱砂方（`--accent` #C2402A）+ 纸白宋体「低」**——界面内窄栏那枚印章的放大版。

已于 2026-10-07 定选。曾并列评估过三个方向（闲章「日」/ 印章「低」/ 信笺折角），选定印章方案，理由是它与界面内品牌符号同构、**不需要改动界面任何一处**；落选两套已删除。

## 文件清单

| 文件 | 说明 |
|---|---|
| `icon.svg` | 256 母版（32px 及以上使用）。宋体 600，与界面内印章同字重 |
| `icon-small.svg` | 16 / 24px 专用母版。宋体 **700**，见下方「两套母版」 |
| `icon.ico` | 七档整包图标（16/24/32/48/64/128/256，PNG 压缩条目） |
| `png/` | 各档 PNG，供预览与取用 |
| `图标预览.html` | 单文件验收页（图片已内联）：真实尺寸、深色底、像素放大、任务栏模拟 |
| `图标预览.模板.html` | 上面那页的可编辑源（引用 `png/`，由打包脚本内联成 data URI） |
| `打包.sh` / `打包.mjs` | 重新生成的流水线，母版改完跑 `bash 打包.sh` |

## 两套母版与实测记录

Windows 任务栏与资源管理器小图标是 **16px**，大尺寸母版直接缩下去会糊，故拆分：

| 尺寸范围 | 母版 | 字重 |
|---|---|---|
| 32–256px | `icon.svg` | 宋体 600（与界面内印章一致） |
| 16 / 24px | `icon-small.svg` | 宋体 **700**（光学补偿，600 在 16px 会灰掉） |

**为什么小尺寸不做「几何简化」**：曾把「低」压成 4 笔几何骨架（亻的撇与竖、氐的横与斜钩），
16px 实测**被读成「介」**——笔画一少，字形就不是那个字了。改用真实字形 + 加粗后，16px 放大仍能认出。

**也试过微软雅黑 Bold**：清晰度略胜宋体，但会破坏「宋体主导」的字体纪律，未采用。

## 重新生成

```bash
cd front_design/app-icon
bash 打包.sh
```

流程：Edge 无头逐尺寸栅格化（256 窗口渲染、SVG 贴左上角、按目标尺寸**精确裁切**，不重采样）
→ 纯 Node 裁切/编码 → 合成单一 `.ico` → 生成自包含预览页。

### 四个已踩过的坑（都已写进脚本）

1. **Edge 窗口有最小尺寸**，16px 窗口出不了图 → 大窗口渲染再裁切。
2. **Chromium 把 `--screenshot` 路径里的反斜杠当转义字符** → 一律转正斜杠。
3. **必须加 `--disable-lcd-text`**。小尺寸母版用字体渲染，不禁用次像素抗锯齿会在字缘留**彩色镶边**（实测 16px 下带彩边像素 116 个、最大色偏 90；禁用后 0 个、1.0）。
4. **Edge 无头进程会累积**，累积后渲染开始静默失败 → 脚本内置三次重试；仍失败时先 `taskkill //F //IM msedge.exe` 再重跑。

另：**本机 Node 子进程被运行环境拦截**（`spawnSync` 返回 `status:null`），脚本内无法直接调起浏览器，故流水线拆成 bash + node 两半。
