# 05 · 交互流程与文案

文案全部为定稿，可直接进代码。走查方法：对照本页逐条核对界面文案，术语以 `CONTEXT.md` 为唯一依据。

## 1. 文案语气规范

三条基调：

1. **平实温柔**：短句、口语但不出戏；不用感叹号轰炸，一段文案至多一个句末标点加重。
2. **不卖惨不煽情**：不出现「坚强」「加油」「你并不孤单」这类口号；陈述陪伴事实，不喊话。
3. **Agent 自称「我」，称用户「你」**：不使用「小编」「本应用」等机器称谓。

禁用词（来自 CONTEXT.md，界面出现即 bug）：情绪记录、情绪数据、用户画像、人设、推送、打扰、预警、报警、紧急联系人、离线模式、安全模式、笔记、帖子。

## 3. 交互流程

### 3.1 首启（无条目、未配置模型）

进入 → 单屏陪伴工作台：左栏编辑器占位（今天已写区隐藏），右栏对话降级空态 + 降级横幅常驻 → 用户可立即书写（原则 1）。可选路径：横幅「配置模型」或窄栏「设置」→ 弹窗 → 保存 → 横幅消失。

### 3.2 记录流

输入文字 →（可选）贴图 → 「记录今天」→ 编辑器清空 → 「今天已写」顶部插入新卡片（心情行=「心情记录生成中…」）→ 分析完成 → MoodRecordCard 落印抵达（见 02 §4.1；「静」档下直接呈现）。

- 降级模式：全流程不变，仅心情行不渲染。
- 条目查看与编辑（13 增补 / 后续修订）：今天条目卡点击展开全文（再点收起），展开后出现「编辑 / 收起」；点「编辑」→ 内容载入**上方主编辑器**（提示"正在修改 X 写下的那条日记"，按钮变「保存修改」、旁有「取消」）→ 保存后**同一篇**（id 不变）原文覆盖、**时间刷新为保存时刻**、旧心情记录作废并重新分析（先回到"心情记录生成中…"）。编辑仅限"今天"；过去的条目与整合日记一律只读，接口层同样拒绝修改。
- 分析失败（重试一次仍失败）：条目保持 analyzed=0，界面停留在「生成中」态，由后台兜底补扫收口；**不展示错误**（不制造焦虑）。
- 跨天：日期变更后「今天已写」清空，昨日条目移入历史抽屉。

### 3.3 唤醒流

打开应用即为一次唤醒：会话为空时，Agent 开场流式抵达（有日记时带唤醒注脚；无日记时一般问候）→ 用户可回复。

- 会话进行中：回到应用即续聊，不打断。
- 「新的唤醒」：不弹确认（轻量应用），直接开新会话并重新注入最近日记。
- 「历史会话」：右侧抽屉滑出 → 点选 → 载入并续聊。

### 3.4 对话中模型失联

当前轮流式中断 → 行内提示（见文案表）+ [重试] → 重试仅重发最后一轮；日记面板不受任何影响。

### 3.5 危机应对

- 对话链路：用户输入命中 → Agent 回复 = 共情正文（正常流式）+ HotlineCard（正文后追加）→ 对话继续，不阻断、不变红、无弹窗。
- 分析链路：心情记录 crisis=1 → 「今天已写」或历史抽屉中对应条目卡出现照顾标记（安静角标，无横幅无红点）。

### 3.6 降级恢复

保存配置或调用恢复 → 横幅 200ms 消失 → 对话面板从降级空态回到可用态 → 分析兜底补扫，「今天已写」与历史抽屉中的 MoodRecordCard 陆续淡入（无需用户操作）。

### 3.7 配置流

v0.1.0 入口两处：①降级横幅「配置模型」（降级时的最短路径）；②窄栏底部「设置」按钮（常驻，任何时候可进入）。两处打开同一个极简配置弹窗 → 五字段（Base URL / API Key / 模型名 / 温度 / 思考强度）→ 保存即生效；API Key 掩码回显，不回显明文；温度与思考强度带注释，真实作用于模型调用。完整设置界面仍属 v0.3.0，设置按钮仅承载模型配置。

### 3.8 历史日记流

窄栏「历史」→ 抽屉从左侧滑出（340px，其余内容覆盖轻遮罩）→ **一天一行**（日期标题 + 预览两行 + 当天心情摘要），点某天 → 抽屉收起、左栏打开**那一天的日记页** → 滚动到底加载更早 → 关闭方式：× / 点遮罩 / 再点「历史」。抽屉为只读浏览（v0.1.0 不提供编辑入口）。

### 3.9 长期记忆流（09 增补）

窄栏「记忆」→ 工作台切到记忆页：基本信息 / 性格画像两栏 → 条目可原地编辑、删除（原位二次确认）、自行添加（＋ 写一条）；来源标记区分「你写的 / 它记下的」→ 再点「记忆」回工作台（对话流不中断）。用户在此的修改与 Agent 维护等效，下一回合对话即生效。

### 3.10 某一天的日记页（11 增补）

历史点某天 → 左栏显示该天：标题（一律具体日期：2026/10/5 周一）+「回到今天」；主文是这一天整合后的日记（跨天后由程序拼接，模型分析出日心情，含照顾标记；未整合时显示"这一天的日记还在整理中。"），其下「这一天写下的」列当天原文（条目只显示时刻，图片可点大图）。过去的日子只读（条目与整合日记均不可编辑）；「今天」仍是编辑器视图。可拖拽的分隔线有两处：工作台两栏之间（左右拖，双击复位），以及「今天」编辑器与「今天已写」之间（上下拖，双击复位）。

### 3.11 主题切换（14 增补）

窄栏底部「夜 / 日」按钮：显示**当前**主题（日间「日」、夜间「夜」），点击**即时**换纸、无过渡动画（02 §4.1 禁用项）。首次运行跟随系统偏好，之后记住选择（localStorage）。两套纸色 token 见 02-视觉规范。

## 4. 状态与数据对应（前端视角）

| 界面状态 | 数据来源 |
|---|---|
| 降级横幅 | GET /api/settings/model 为空，或对话/分析接口返回降级态 |
| 分析中 | entries.analyzed = 0 |
| 照顾标记 | moods.crisis = 1 |
| 唤醒注脚 | 新建会话且最近有条目 |
| 强度点 | moods.intensity 1-10 |
| 情绪 chips | moods.labels[] + 02 号文档色族映射 |
| 今天已写 | entries 中 created_at 为今天的当天条目（倒序） |
| 历史天列表 | GET /api/diaries（一天一行；整合日记的心情摘要优先） |
| 日页 | GET /api/diaries/{day}：日心情（kind=daily 的心情，置顶）+ 当天原文（每条各自带心情；整合正文不整篇平铺） |
