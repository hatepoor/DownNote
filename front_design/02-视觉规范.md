# 02 · 视觉规范（双主题 · 信笺铅字）

> 轮次 01 用户选定方向 A「信笺铅字」。北极星：深夜在书桌前给信任的人写信——纸是冷的，字是认真的，只有一点朱砂是热的。
> 浅色主题「信笺」为默认；深色主题「夜笺」通过 `<html data-theme="dark">` 切换。全部 token 为 CSS 自定义属性。

## 0. 排版纪律（本方向的灵魂，优先级高于一切装饰）

1. **宋体主导**：日期、标题、日记正文、摘要用 Noto Serif SC；UI 控件与辅助文字用 Noto Sans SC；时间戳用等宽字体（Consolas / Cascadia Mono）。
2. **无卡片**：内容区块不用圆角卡片＋阴影，用**上下 1px 规则线**分隔；面板之间用 1px 竖规则线。
3. **层级靠对比**：墨色 2px 粗规则线只出现在面板头（每天一次）；日期/meta 用等宽小字＋字距；日记正文 15px/1.9 宋体是版面主角。
4. **朱砂纪律**：全站唯一暖色，只允许出现在——主按钮、流式光标、唤醒入口、品牌印章、焦虑标签描边。其余一切皆为纸与墨。
5. 结构改造状态：**画布当前为过渡态**（保留卡片容器、情绪标签用压灰底），无卡片规则线版式为下一批改造项。

**朱砂是全站唯一暖色**——这是色彩身份，不是色值漂移。同一屏里不出现两块同强度朱砂：**品牌印章用满饱和 `--accent`，实心主按钮用降饱和 `--accent-fill`**（大面积不刺眼，也与印章形成主次）。

**对比度锚点（轮次02 新增）**：纸是低对比的底色，但不能低到让结构消失。三条下限——规则线 1.5–1.7:1、输入框边与未填充刻度 2.0:1、弱文字 3.0:1。低于此界面会读成「未渲染完成」，高于此开始出现层级噪声。原 `--hairline` 在浅色下仅 1.24:1，属失效值。

**面色层次（轮次03 新增）**：全站四个面，两两相差半档，让三栏读成**不同的材料**，而不是一块连续的纸。相对关系固定为：窄栏（最深）＜ 对话栏（偏暖）＜ 正文栏（基准）＜ 书写卡与浮层（最亮）。

> 注意：`--bg-sheet` 只比 `--bg-page` 亮约 1.03:1——这是**刻意的**。纸卡「浮起半档」靠的是边框＋微影＋这点色差三者叠加，不是靠色差单独承担。若日后觉得卡片不够立得住，**先加边框对比度，不要靠继续提亮卡片**（正文栏已接近纯白，没有提亮空间）。

## 3. 圆角 / 间距 / 阴影

**圆角纪律**：全局 2px（按钮、输入框、印章、标签、**书写卡**）；浮层（弹窗/lightbox/抽屉）4px。**没有大圆角**。

间距（4px 基）：4 / 8 / 12 / 16 / 20 / 24 / 32。面板内边距 24-30；区块间以规则线＋16px 呼吸分隔，不用卡片堆叠。

阴影：**常态零阴影**。只有两处例外——
1. **浮层**（弹窗 4 层、抽屉 3 层、lightbox）：实现以 token 表达（双主题各一套）：`--shadow-soft`（抽屉）、`--shadow-dialog`（弹窗）、`--shadow-lightbox`（灯箱）；深色下为纯黑、不透明度提高。
2. **书写卡**（轮次03 新增）：`--sheet-shadow`，双层级微影。它是「桌上的一张纸」，需要从纸面浮起半档。

其余一切靠规则线加深或朱砂描边表达，不用阴影。

**规则线渐隐（轮次03 新增）**：面板头与区块边界的水平规则线，右端 24% 收梢渐隐（`linear-gradient(90deg, 线色 0%, 线色 76%, transparent 100%)`）——信笺页眉的那道线不会横贯到底。**条目之间的分隔线仍用实线**：渐隐只用于「区块边界」，不用于「条目分隔」。

滚动条：**细、静**——透明轨道，滑块取纸色系（`--scrollbar-thumb`，悬停 `--scrollbar-thumb-hover`，双主题各一套），方角、无系统灰。

原生控件：`color-scheme` 随主题声明（信笺 `light`、夜笺 `dark`）——`<select>` 下拉列表、数字微调箭头等系统绘制的部件自动跟随纸色，夜间不出现白块；浅色主题即使系统为深色也强制浅色。

下拉（配置弹窗·思考强度）：**自绘组件**（SelectMenu，页内绝对定位）——浏览器弹出层（base-select picker）存在错位与收起重影等内核怪癖，弃用。触发框为按钮：选中值垂直居中、右侧小三角取 `--ink-2`，展开时与列表同为朱砂 1px 描边；列表纸底、浮层圆角（4px）与弹窗投影，贴触发框**下方全宽**展开；选项悬停/选中 `--accent-soft` 淡底、选中朱砂字（180ms 过渡）；开合走落墨（320ms）；键盘 ↑↓/Home/End/Enter/Esc，点击外部关闭。

## 3.5 纸面工艺

「纸感」不靠配色，靠物理细节。参考稿已落地，实现时不得省。

1. **纸纹**：整屏一层极淡颗粒——SVG `feTurbulence` 去饱和后平铺 200×200（噪点层烘焙不透明度 0.12），`--grain-op` 浅色 0.85 / 深色 0.80，混合模式浅色 `multiply` / 深色 `screen`（等于深色纸上的浅颗粒）。作用于整张纸（含浮层之上，因其同属纸面），`pointer-events:none`。
   目的：让大面积留白读成「纸」，而不是「空 div」。这是本方向最廉价也最有效的一笔。

### 书写区形态（轮次03 定稿）

**信笺卡**：编辑器是一张放在桌面上的纸——底 `--bg-sheet`（比正文栏亮半档）、1px `--hairline` 边框、2px 圆角、`--sheet-shadow` 微影；卡内**左侧一条 `--margin-line`（朱砂 16% / 深色 26%）竖向页边线**，正文自页边线右侧 18px 起排；聚焦时边框转 `--hairline-strong`。贴图与「记录今天」收进卡片内部（底部分隔线之下），卡片即完整的书写单元。

页边线是信纸的固有构件（左侧留白栏），**只有一条、且是竖向的**，不是装饰。**横格线仍然禁止**（见下）。

> 轮次02 曾试做「稿纸横格线」（编辑器内铺 1px `--rule`、周期 = 行高 28.5px、压在字身框下沿）作为书写区的实体提示。用户评审判定：观感近似下划线装饰，与本方向「低视觉噪音」相抵，**已移除，`--rule` token 一并废弃**。不要自行加回。
>
> 轮次03 改用「信笺卡」重新给书写区实体感：**靠卡片边界与页边线，而不是格线**。这条区分是本次评审的结论——竖向单线与横向重复线在观感上不是一回事。
>
> 若日后确需恢复书写区实体感，按以下优先级取舍，且每次只上一项：① 极轻的 `--bg-inset` 凹印底 → ② 单条 `--hairline` 顶线或底线 → ③ 稿纸横格线（需重新评审）。

**规则线纪律（补充）**：同一位置只允许一条线；区块分隔一律「线 + 14–16px 呼吸」，禁止「线—字—线」的双线夹字。

## 4. 动效 · 纸与墨

> **第一纪律：纸上不会飘。** 除抽屉「抽纸」外，入场一律不使用位移。位移是屏幕的语言，不是纸的语言。

时长 150–260ms；**无弹跳、无回弹**；`prefers-reduced-motion: reduce` 下全部停用（光标静置）。

### 4.1 只有两个原生动作

| 动作 | 用于 | 规格 |
|---|---|---|
| **落墨** `inkBleed` | 内容出现（流式文字、气泡、弹窗/遮罩） | **只用透明度**，0→1，快出慢收 `cubic-bezier(.16,1,.3,1)`，约 320ms。像墨浸入纸 |
| **落印** `stampPress` | 成块内容压上纸面（新条目卡、心情记录行） | opacity 0→1 ＋ `scale 1.03 → 1`，条目 260ms / 心情记录 200ms，`cubic-bezier(.2,.8,.3,1)` |

**「落印」的 scale 方向是本节最容易做错的地方**：`0.96 → 1` 是弹窗的语法（从远处小尺寸浮现）；铅字压上纸面必须 `1.03 → 1`——从略高处按下（近大远小），落定即静止。

**禁用项**（曾试做，已废止，不要再用）：`translateY` 入场（「上浮淡入」）、按序错峰编排、首帧整体浮现、主题切换遮罩渐变。这些都属通用 Web 应用动效，与纸的物理性相抵。

### 4.2 位移的唯一去处：抽纸

抽屉与遮罩：抽屉 260ms、遮罩 200ms，曲线同为 `cubic-bezier(.32,.72,0,1)`——起步快、末端收住，像把一张纸从纸叠里抽出来。这是全站唯一允许的位移。

### 4.3 档位

由根节点 `data-motion` 切换，**默认「墨」**。

| 档位 | 内容 |
|---|---|
| **墨**（默认） | 落墨 ＋ 落印 ＋ 「生成中…」1900ms 极轻呼吸（0.6 → 1） |
| **静** | 内容不做任何入场（元素直接呈现），只保留状态反馈与抽纸位移 |

> 参考稿 `陪伴工作台-定稿.html` 窄栏的档位开关是**演示控件**，不属产品界面、不进产品设置；v0.1.0 不实现该开关。（主题切换是产品功能，已随 14-夜间主题 落地：窄栏「夜 / 日」按钮——2026-10-07 起切换带**整页交叉淡化**，见 §4.4 主题切换；遮罩过渡仍是禁用项。）

### 4.4 状态反馈（触感，不受档位与「纸不飘」约束）

- **悬停**：规则线加深（`--hairline` → `--hairline-strong`）或朱砂描边（见 §3），非位移、非阴影。
- **按压**：按钮下移 1px，120ms。
- **主按钮禁用态**：**未填墨的铅字框**——透明底 ＋ 1px `--hairline-strong` 描边 ＋ `--ink-3` 文字；输入非空即「落墨」回到实心朱砂。这是「记录今天」空内容时的唯一禁用表达。
- **焦点**：`:focus-visible` 用 `--focus-ring` 2px 外描边、offset 2px。键盘可达性，不可省。
- **流式光标 ▍**：朱砂色，1200ms 呼吸（1 → 0.28 → 1）。低于 1s 会读成「指示灯闪烁」，1200ms 才读成「呼吸」。
- **在场信号（轮次03 新增）**：对话面板标题左侧一枚 7px 朱砂圆点，3400ms 呼吸（`scale 1 → .78` 兼 `opacity 1 → .5`），外圈 `--accent-soft` 光晕。它是「它在」的唯一视觉证据——与光标呼吸同源，属**状态指示**而非入场动效，两档（墨/静）与 `prefers-reduced-motion` 之外一律保留。
- **主题切换**：**整页交叉淡化**（View Transitions `document.startViewTransition`，320ms 落墨曲线；`prefers-reduced-motion` 下瞬时，不支持的内核回退瞬时）。2026-10-07 用户验收推翻原「即时」决定——日夜互换反差大，瞬时跳变刺眼。在页面上盖一层渐隐的「换纸遮罩」仍是禁用项：淡化发生在两帧画面之间，不新增任何叠加层。
- 演示控件（主题/动效开关）激活态用**墨色**而非朱砂——避免污染画面的朱砂用量判断。

### 4.5 滚动边缘渐隐（15-动效优化 增补）

滚动容器内容在边缘 22px 内渐隐，**随滚动位置连续变化**（到顶/到底时该侧为 0）——不是常驻遮罩，没有"突现"的遮罩层。实现：`.scroll-fade`（`mask-image` 渐变）＋ `--fade-top/--fade-bottom` 由 JS 随 scroll/内容/尺寸变化驱动。接入：今天已写、日页、对话消息区、历史抽屉。

## 5. 图标

内联 SVG 描边（24 视框、stroke 1.75、方角 cap/join——与方角控件同语言），只线性不填充；品牌印章为唯一实色块。

### 5.1 品牌符号与应用图标

**品牌符号 = 品牌印章**（满饱和 `--accent` 实心方块 + 纸白宋体 600 单字「低」）。界面内为 34×34（窄栏顶部）；应用图标是同一枚印章的放大版，不是另立的图形记号。据此 03 号文档原先「墨点＋纸页极简记号，非文字」的写法已废止。

**应用图标用满饱和 `--accent`（#C2402A），不用实心按钮那支降饱和的 `--accent-fill`。** 图标就是那枚印章，降饱和只属于大面积实心按钮。

尺寸纪律（Windows 桌面）：

- 任务栏与资源管理器小图标为 **16px**；「低」7 画在 16px 必糊，故 **16 / 24px 用单独的小尺寸母版**，不得把大尺寸母版直接缩下去。
- 小尺寸母版**不做几何简化，用真实字形并把字重提到 700** 做光学补偿。实测：把「低」压成 4 笔几何骨架后，16px 被读成「介」——笔画一少，字形就不是那个字了。
- 七档：16 / 24 / 32 / 48 / 64 / 128 / 256，合成单一 `.ico`。栅格化时**必须禁用次像素抗锯齿**（Edge 无头加 `--disable-lcd-text`），否则字缘会留彩色镶边。
- **Windows 上 `webview.start(icon=…)` 不生效**（pywebview 源码注明仅 GTK/QT）；应用图标只能由 PyInstaller `EXE(icon=…)` 嵌进 exe 资源——那是唯一入口，漏了会静默回落成默认图标。

资产与打包流水线见 `front_design/app-icon/`（已完成定选，全套实测记录在该目录 README）。
