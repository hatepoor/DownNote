# front_design · 前端设计文件夹说明

本目录是低落日记**前端设计的唯一方案来源**：设计原则、视觉规范、布局页面、组件规划、交互流程与文案，以及定稿页面的 HTML 参考实现。设计方案先落文档再写代码；实现时在对应模块文档的 todolist 中引用这里的方案。

## 阅读顺序

- 新接触本目录：01 → 02 → 03 → 04 → 05，随时打开定稿 HTML 对照。
- 写代码时：02（token）+ 04（组件规格）+ 定稿 HTML（视觉基准）三件套对照；文案一律取自 05。

## 版本口径

- 本方案当前覆盖 v0.1.0（MVP 陪伴闭环）；v0.2.0（主动陪伴）、v0.3.0（回顾/设置）只做「预留位」说明，不展开设计。
- 设计对象是 Vue 前端（`frontend/`），运行在 pywebview 桌面窗内；平台约束见 01 号文档。
- 高保真视觉稿在 Ardot 画布《低落日记 · 前端设计》维护：**文档为准、画布与定稿 HTML 为参考**；三者冲突时先改文档。
