## 关键规格

### DiaryPanel / TodayEntryCard

- 面板头：「今天」宋体 16 + 日期右对齐（--fs-caption）。
- TodayEntryCard：内边距 16、正文最多 3 行截断；心情记录行规则同 EntryCard；分析中/降级态规则见 03 §2。
- 抵达动画：新条目插入「今天已写」顶部时走「落印」（260ms，规格见 02 §4.1）；「静」档下直接呈现。

### DiaryEditor 日记编辑器

- textarea 最小高 200px，随内容增高（上限约视口 45%，超出滚动）。
- 「＋贴图」隐藏式：无图时显示；贴图后该行变为预览（72px 缩略 + 文件名 --fs-caption + 移除 ×）。
- 提交中按钮转「记录中…」并禁用，防重复提交。

### EntryCard / MoodRecordCard 心情记录行

- chips：高 24px、圆角 full、内边距 2×10、--fs-helper；多标签横排 gap 6，超出换行。
- 强度点：10 枚 6px 圆点、gap 3，位于 chips 右侧（放不下则换行到首）；不加「强度」文字前缀，语义交给 aria-label。
- 摘要：宋体 --fs-summary --ink-2，前缀「——」引文式。

### DiaryHistoryDrawer 历史日记抽屉

- 宽 340px、左侧滑出、3 层阴影；头部「历史日记」宋体 + 关闭 ×；内容区独立滚动。
- 抽屉开启时，右侧内容区覆盖轻遮罩；点遮罩/×/再次点「历史」关闭。
- 卡片复用 EntryCard 规格（正文最多 4 行、配图缩略 72px）。

### ChatBubble 消息气泡

- Agent 气泡最大宽 85%；用户气泡同宽、右对齐。
- 流式时内容容器保持 min-height 一行高，避免跳动。

### HotlineCard 求助资源卡

- 暖纸卡：--accent-soft 底、圆角 xl、内边距 16；标题行小图标（手捧心）+「一些可以打给你的声音」（宋体）。
- 每条热线一行：名称 + 地区（--fs-caption）+ 电话（--fs-body、500）+「复制」ghost 小按钮；复制成功按钮文案转「已复制」1.5s。
- 卡尾注 --fs-caption --ink-2：「不评判，随时都在。」
- 数据源：后端 hotlines.json 经接口返回；卡片出现在正文之后，不打断流式文本。

### ModelConfigDialog 配置弹窗

- 字段：Base URL（placeholder `https://api.example.com/v1`）、API Key（password 型，回显掩码）、模型名（placeholder 示例模型名）；Base URL 下方注明协议边界——仅支持 OpenAI 兼容的 completions 模式（自动请求 /chat/completions），填到 /v1 一层即可。
- 校验从宽：三字段非空即可保存；保存即生效（PUT /api/settings/model），成功后弹窗关闭、横幅消失。
- 思考强度下拉：自绘组件 `SelectMenu`（不用原生 `<select>`——浏览器弹出层有错位、收起重影等内核怪癖）；触发框下方全宽展开，朱砂描边 + 纸底 + 落墨开合 + 选项悬停淡底；键盘 ↑↓/Enter/Esc、点外关闭；选中值垂直居中。视觉规则见 02 §3「下拉」。
- 说明行：「配置只保存在这台电脑上。」

### DegradedBanner 降级横幅

- 文案定稿见 05；「配置模型」为 link 型按钮（--accent 文字，hover 下划线）。

### EmptyState 空态

- 当天日记版 / 对话版 / 历史抽屉版文案见 05；结构 = 一句宋体主句（--fs-title）+ 一行 --fs-helper 副句，垂直居中，不配插画。

### 图标清单（内联 SVG）

钢笔尖（日记，历史抽屉品牌辅助）、对话气泡（对话面板头辅助）、书本（历史入口）、手捧心（照顾/资源）、加号（贴图）、×（移除/关闭）、复制、历史（时钟回旋，会话历史）、发送（纸飞机）、齿轮（设置）。
