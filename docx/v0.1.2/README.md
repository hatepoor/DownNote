# v0.1.2 · 修复与体验优化

> 状态：已完成（2026-10-08）；**补充修复进行中**——10-记忆即时可见（已完成，待用户复验）、11-记忆分类与归位（进行中）。两项补充修复均经用户决定并入 v0.1.2，不新开版本。Release v0.1.2 已发布；覆盖升级与干净机器验证均已通过。

## 版本目标

聚焦修复 v0.1.1 发布后的用户反馈：记忆写入失效、心情记录生成过慢、心情分类偏少等 8 项问题；修复前先完成项目结构原子化重构（前后端 7 处混装文件拆分），为后续改动提供单一落点。不新增大功能。

## 范围

**做**：00 结构重构（前后端 7 处混装文件原子化拆分）＋ 01~08 用户反馈问题修复。问题来源与用户口径见 [Release 说明草稿](../../docs/release-v0.1.2-draft.md)。

补充修复（发布后并入）：10-记忆即时可见——用户实测「模型写入记忆后记忆页不刷新、需重启」，修复沿用 02 的 SSE 推送模式（见 [modules/10-记忆即时可见.md](./modules/10-记忆即时可见.md)）；11-记忆分类与归位——用户实测「记忆分类混乱」，收紧三段分类定义并把分类变为可改（工具/接口/界面三个口子，见 [modules/11-记忆分类与归位.md](./modules/11-记忆分类与归位.md)）。

**不做**（第二波及以后，见 [路线图](../README.md)）：定时关怀、信号触发、人格模板、回顾可视化、设置界面、密钥加密存储。
