## 背景

用户反馈第一次打开没有引导，不知道怎么使用：不知道先去「设置」配模型、怎么写记录、怎么唤醒对话。

## 方案要点

- 首次启动给一段简短引导（写记录 → 配模型 → 唤醒对话 三步即可），可跳过、不重复打扰。
- **标记与判定**：
  - 标记存前端 `localStorage`，键 `down-note:onboarding-done`；完成或跳过时写入 `1`。
  - 展示条件 = 无标记 **且** 无既有数据（用现有接口探测：条目为空 且 模型未配置）。
  - 不新增后端落点；若后续希望跨壳 / 跨设备一致，再考虑落数据库。
- 判定表：

| 场景 | 标记 | 既有数据 | 是否弹 |
|---|---|---|---|
| 全新安装 | 无 | 无 | 弹 |
| 旧版覆盖升级 | 无（WebView 数据目录随升级保留，但此前无此标记） | 有 | 不弹，并补写标记 |
| 跳过后再次启动 | 有 | — | 不弹 |
| 完成引导后启动 | 有 | — | 不弹 |
| 删库但保留前端存储 | 有 | 无 | 不弹（标记仍在） |
| 删库且清前端存储 | 无 | 无 | 弹 |

- 引导样式贴信笺卡视觉风格，动效与 05 统一；不打断工作台（沿用现有 `v-show` 状态保持）。
