## 背景

鼠标移到对应的日记上没有任何视觉反应，界面缺少交互感，显得平、呆板；用户期望悬停时日记有「凸显」这类反馈。

现状澄清（实施对照）：条目样式现集中在全局 `style.css` 的「条目（今天已写 / 历史抽屉 / 日页共用，规则线无卡片）」分节——迁移后即 `styles/diary.css`；组件内若有 scoped 覆盖，实施时一并调整。

## 方案要点

- 为日记卡片 / 列表条目补悬停反馈：悬停凸显（轻浮起、阴影加深或边框高亮，与信笺卡视觉风格一致）。
- 配合 05 的过渡动画让反馈自然不突兀；**悬停 / 按下 / 选中态共用同一组时长与缓动变量**（避免两处各写一套）。
- 日/夜两套 Token 下都要成立（阴影与描边色随主题变）。
