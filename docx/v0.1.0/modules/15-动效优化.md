# 15-动效优化

## 元信息

- **所属版本**：v0.1.0
- **对应代码**：`frontend/src/style.css`、`frontend/src/utils/scrollFade.ts`、`frontend/src/components/DiaryPanel.vue`、`TodayEntryCard.vue`、`ChatPanel.vue`、`DiaryHistoryDrawer.vue`
- **前置依赖**：12-体验修订、14-夜间主题
- **状态**：已完成（2026-10-06）
- **备注**：验收反馈修订批次（五），执行顺序在 10-打包发布 之前

## 背景

用户验收（第五轮）：① 两处输入框（日记编辑器、对话输入框）的焦点色效太突兀、不好看；② 希望滚动有"渐进渐出"的效果；③ 整体动效可以优化。

## 方案要点

1. **焦点色效平滑化**：编辑器聚焦的 2px 朱砂下划线、对话输入框 / 记忆编辑框 / 条目编辑框 / 配置弹窗字段的边框色，统一为 260ms `cubic-bezier(.16,1,.3,1)`（02 §4.1「落墨」曲线，在设计时窗 150–260ms 内）——原来 150ms 甚至无过渡，色块"啪"地跳出来。
2. **滚动边缘渐进渐出**：新增 `utils/scrollFade.ts`（watch 式组合式，兼容 v-if 分支挂载）。给滚动容器挂 `.scroll-fade`，随滚动**连续**驱动 `--fade-top / --fade-bottom`（0→22px），`mask-image` 渐隐边缘；到顶/到底时该侧为 0（不是常驻遮罩，无"突现"感）。事件源：scroll + MutationObserver（内容/文字变化）+ ResizeObserver（尺寸变化）。接入四处：今天已写、日页、对话消息区、历史抽屉；记忆页两栏暂未接。
3. **落印落地（02 §4.1）**：新条目卡 260ms（opacity 0→1 ＋ scale 1.03→1）、心情记录行抵达时 200ms。**首帧不落印**（设计禁用项"首帧整体浮现"）：DiaryPanel 维护"已知条目 id 基线"，只有新出现的 id 标记 fresh（1 秒窗口后清除，避免分支重挂重放）；心情落印只在 `null → 有值` 的那次变化触发，初始已有记录不触发。
4. **光标呼吸 800ms → 1200ms**（设计稿轮次02 评审后修订值）。
5. `prefers-reduced-motion` 全局兜底覆盖以上全部（既有媒体查询把动画/过渡时长压到 0.01ms）。
