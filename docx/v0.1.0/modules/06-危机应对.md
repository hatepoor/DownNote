## 方案要点

- 两级流水线：`screen()` 关键词初筛（纯本地子串匹配、毫秒级、可离线测，宁敏感勿遗漏）→ 命中才走 `assess()` LLM 复判（判定口径：是否针对"作者本人"；转述新闻/文艺引用 → 非危机；拿不准 → 保守判危机）。
- **复判失败 → 保守返回 True**（ADR-0003）：误标只是一枚安静的照顾标记，静默漏标不可接受。
- 危机判定评**条目原文**（两级），不评 20 字摘要——摘要可能丢信号。
- 应答约束 `CRISIS_RESPONSE_GUIDELINES` 已定稿（共情接住 → 温和递资源 → 不评判不中断；资源卡只出现一次），08-对话Agent 直接引用。
- 求助资源：包内 `resources/hotlines.json` 预置四条全国/北京热线；用户数据目录同名文件可整体覆盖（按地区补充）。
- 前端 CrisisMark：crisis=1 时心情行下安静角标"♡ 这一天，多照顾自己一点"，无横幅无红点无警告样式。
