## 方案要点

1. **切换机制**：`<html data-theme="dark">`（设计稿约定），两套 token 原已就绪；挂载前 `initTheme()` 先落主题，避免启动时闪一下浅色。
2. **入口**：窄栏底部（设置上方）「夜 / 日」按钮——显示**当前**主题（日间「日」+ 太阳图标、夜间「夜」+ 月亮图标）。设计稿 §4.1 把「主题切换遮罩渐变」列入禁用项，轮次02 评审后修订明确"主题切换改为**即时**"；**2026-10-07 用户验收推翻**：瞬时跳变刺眼，改为**整页交叉淡化**（`document.startViewTransition`，320ms 落墨曲线，规格在 style.css `::view-transition-*`；`prefers-reduced-motion` 下瞬时、不支持的内核回退瞬时切换）。遮罩叠加仍禁用。
3. **记忆**：localStorage `down-note:theme`；首次运行跟随系统偏好 `prefers-color-scheme`。
4. **色值同步设计稿轮次02**：浅色 `--hairline #CEC7B6`、`--hairline-strong #B5AC97`、`--ink-3 #94908A`；深色 `--hairline #423F38`、`--hairline-strong #55514A`（对比度锚点上调）；新增双主题阴影 token `--shadow-soft / --shadow-dialog / --shadow-lightbox`，替换抽屉/弹窗/灯箱 4 处硬编码阴影；新增 `--scrollbar-thumb(-hover)`，滚动条改为**细、静**（透明轨道、纸色滑块），去掉系统默认灰条在夜间的突兀。
5. **主按钮禁用态**按 02 §4.4 落地为「未填墨的铅字框」：透明底 ＋ 1px `--hairline-strong` 描边 ＋ `--ink-3` 文字（记录今天 / 发送 / 保存 三处；底座加透明描边使启停切换不跳高）。
6. **明确未做**（用户限定"只参考颜色"，其余设计稿轮次02 条目待后续同步）：纸纹层、落墨/落印动效、光标呼吸 1200ms。
