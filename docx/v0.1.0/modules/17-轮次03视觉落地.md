## 方案要点

1. **面色四档**（层次感的根）：窄栏 `--bg-inset`（最深）＜ 对话栏 `--bg-companion` ＜ 正文栏 `--bg-page`（基准）＜ 书写卡/浮层 `--bg-sheet`（最亮）。浅色 #EAE7DE/#EFEBE2/#F5F3EC/#FDFCF8，夜笺 #131211/#21201C/#1C1B18/#262522。`--bg-surface` 更名 `--bg-sheet`；`--hairline` #C9C2B0、`--ink-3` #8E8A84 随底面压深重算回锚点。
2. **信笺卡**（书写区）：`.sheet` = --bg-sheet 底 + 1px hairline 边 + 2px 圆角 + `--sheet-shadow` 微影 + `::before` 左侧 `--margin-line` 竖向页边线（左 22px，正文左缩 18px）；textarea min 186px / max 42vh、行高 2.1；贴图与「记录今天」收进 `.sheet-foot`（顶部分隔线之下）。宽 472→504（内边距 30→24）。
3. **排版节奏**：「今天」宋体 27px/600/字距 5px vs 「对话」16px/4px；面板头墨线（2px）与对话头线（1px）**右端 24% 收梢渐隐**（条目分隔仍实线）；区块间距 26px；`.cap::before` 4px 朱砂方点；正文行高 2.1、消息 2.05、条目 2.05。
4. **细节**：对话面板头 7px 朱砂呼吸点（presenceBreath 3400ms）；用户气泡 `border-radius: 2px 2px 0 2px` + 1px `--margin-line` 描边；心情 chips 透明底 + currentColor 描边 + 圆角 1px；强度点拆 `.on/.off` 双色（ink-2/hairline-strong）；纸纹层 `.grain`（feTurbulence SVG 200×200，opacity .85/.80，multiply/screen）落进 App.vue；主按钮实色朱砂（--accent，回归参考稿；--accent-fill token 保留未用）。
5. **编辑器定高拖拽退役**：信笺卡随内容增长（max 42vh），`editor-area`/`sash-h`/`down-note:editor-height` 全部移除。
