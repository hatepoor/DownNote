## 背景

用户验收（第三轮）提出：① 今天与过去的条目都"固定着"点不进去，没法查看全文；② 过去日记不应随意修改——只有"今天"的条目可以改（用户拍板：**过往一律锁定、不留痕、不需要理由**）；③ 「今天」编辑器与「今天已写」之间的分隔栏位置也要可调。

## 方案要点

1. **查看**：今天条目卡 3 行截断，点击展开全文、再点收起；展开后出现「编辑 / 收起」操作行（点「编辑」把内容交给**上方主编辑器**，卡片收回）；过去条目在日页本就是全文只读展示，不另加点击行为。
2. **编辑（仅今天，走主编辑器）**：点条目「编辑」→ 内容载入主编辑器（提示"正在修改 X 写下的那条日记"，按钮变「保存修改」、旁有「取消」，贴图入口暂歇）→ `PUT /api/entries/{id}`：**原文覆盖、时间刷新为保存时刻（同一篇，id 不变）**、清除旧心情记录 → 置回未分析 → 后台重新分析（降级时留给兜底扫描）；界面先回到"心情记录生成中…"，数秒后新标签落定。正文 strip 后为空 → 400。
3. **锁定**：非今天的条目（含整合日记）一律 400「过去的日记不能修改」——接口层硬校验，界面同时不提供编辑入口（双保险）。
4. **面板内分隔栏**：编辑器改为固定高度区域（文字超出时内部滚动，不再自动撑高），下方加横向拖拽柄：160px～屏高 66%，双击复位 300px，高度存 localStorage（`down-note:editor-height`）；过去的日页没有编辑器，自然没有这条线。
