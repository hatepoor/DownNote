## 方案要点

- 只做 OpenAI 兼容协议（ADR-0002）：接入对象统称**模型服务**——裸 LLM 或带人设/工具的 agent 服务均可，协议上无差别；本模块不假设远端是裸模型，我们的系统提示词照常作为消息下发，远端如何采纳由它自己决定。
- 模型调用**统一走 langchain-openai**（ADR-0005）：`agent/llm.py` 提供 ChatOpenAI 工厂（三件套 → 模型实例），分析、危机复判与全部智能体共用，不手写 httpx 调用。
- 错误归类：连接失败/超时/鉴权失败/响应异常统一封装为"模型不可用"类可降级异常，业务层捕获后进入降级模式；其余异常视为程序 bug 不拦截。
- 配置接口"直接换"：PUT 保存即生效，无连通性测试按钮，无多套配置；api_key 经 config.py 写入 `.env`，base_url/model_name 入 settings 表；GET 对 api_key 只回掩码。
