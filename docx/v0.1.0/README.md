# v0.1.0 · MVP 陪伴闭环

## 版本目标

跑通"记录 → 分析 → 唤醒对话"最小闭环：用户用文字和图片记录低落时刻，Agent 在后台把日记条目分析成心情记录；用户唤醒 Agent 时，它先读最近日记了解状态，再展开有状态的陪伴对话。危机应对与降级模式随链路内置。

## 范围

**做**：文字/图片记录、后台分析（心情记录 = 标签 + 强度 + 一句话摘要）、多智能体（主智能体 + 回顾/记忆管理子智能体，LangGraph）、长期记忆（基本信息 + 性格画像条目，前端可查看编辑）、唤醒对话（先读最近日记）、危机应对（关键词初筛 + LLM 复判，共情 + 提供求助资源）、降级模式、OpenAI 兼容模型配置（直接换）、打包 exe。

**不做**（第二波及以后，见 [路线图](../README.md)）：定时关怀、信号触发、人格模板、托盘与系统通知、回顾可视化、设置界面、密钥加密存储、会话压缩、上下文超限处理。
