# v0.1.0 · 架构设计

## 1. 技术形态

Vue 3（Vite + TypeScript）前端 + Python（FastAPI + APScheduler + SQLAlchemy ORM + SQLite）后端 + pywebview 壳 + PyInstaller 打包。Python 环境与依赖由 uv 管理（见 AGENTS.md）。跨进程方式：pywebview 加载页面，页面通过 HTTP 访问本机 FastAPI。

## 4. 数据模型

**日记条目 entries**：id、content（文字内容，可与图片同条）、image_path（相对 images/，NULL 即无图）、created_at、analyzed（0/1）。无 kind 字段——文字与配图是同一条日记的两个部分。

**心情记录 moods**：id、entry_id（外键 → entries，ON DELETE CASCADE，UNIQUE——一条日记一条心情记录，重分析走 UPDATE 覆盖）、labels（JSON 数组，如 ["低落","焦虑"]）、intensity（1-10）、summary（一句话摘要）、crisis（0/1）、analyzed_at、model（产出它的模型，可追溯）

**对话消息 messages**：id、session_id、role（user/assistant）、content、created_at——短期记忆载体，追加式

**会话 sessions**：session_id（主键）、started_at、last_active_at——会话生命周期，供回顾检索与记忆维护扫描

**长期记忆 long_term_memories**：id、category（basic=基本信息 / psych=性格画像条目）、content（一句话事实，纯文本）、updated_by（agent/user）、created_at、updated_at——全量加载进会话

**模型配置**：settings 表 key-value 只存非敏感项（base_url、model_name）；**api_key 存用户数据目录的 `.env`，python-dotenv 加载（load_dotenv）、写入（set_key）**——加密属 v0.3.0（ADR-0002）。

索引与版本：entries(created_at DESC)；entries(analyzed) WHERE analyzed=0 部分索引（供兜底扫描）；messages(session_id, created_at)；schema 版本用 PRAGMA user_version 递增迁移。

## 6. 关键机制

- **降级模式判定**（ADR-0004）：settings 无模型配置，或 llm.py 调用抛出连接/鉴权/超时类错误 → 全局进入降级态；配置成功保存或调用恢复 → 退出。分析、对话入口在降级态下直接拒绝并返回明确状态。
- **危机判定流程**（ADR-0003）：分析管线与对话链路都把文本送 crisis.py——第一步关键词初筛（纯本地、可离线测），未命中直接放行；命中后 LLM 复判定级；确认危机则应答切换为"共情 + 求助资源"话术，并在心情记录上打危机标记。
- **唤醒流程**（FR-3）：唤醒 → 取最近 N 条日记条目及其心情记录注入上下文 → 系统提示词约束陪伴基调 → 流式对话。
- **分析时机**：默认上传即析（后台队列），APScheduler 定时兜底扫描未分析条目；最终取舍在 05 模块定（待定项）。
- **Agent 架构（ADR-0005）**：LangGraph 多智能体——主智能体承接当前会话，回顾/记忆管理子智能体经工具调用派发。消息用 SystemMessage/HumanMessage/AIMessage 区分，会话严格追加（历史不改写）保 prefix cache；短期记忆 = messages 表，长期记忆 = long_term_memories 表（全量加载）；checkpointer 同库独立表、只做图状态恢复。危机检测保持在管线层前置，不交给模型自主决策。v0.1.0 不做会话压缩与超限处理。
- **提示词管理**：分析/危机提示词在 `core/prompts.py`，智能体提示词在 `agent/prompts.py`，全中文，话术是内容资产，禁止散落业务代码。
- **配置加载与保护**：`config.py` 是配置的唯一入口——启动时 `load_dotenv(<用户数据目录>/.env)`，密钥写入用 python-dotenv 的 `set_key`。保护措施：`.env` 已加入 `.gitignore` 与 `.zcodeignore`；GET /api/settings/model 对 api_key 只回掩码；日志与异常信息禁止输出密钥；不做文件 ACL，加密属 v0.3.0。

## 7. 打包与分发

`scripts/build.py` 一键构建：先 `npm run build` 产出 frontend/dist，再 PyInstaller 按 `down_note.spec` 打 exe（嵌入 dist 与 resources）。发布物先走 zip 压缩包，安装器（Inno Setup）后置。Windows 10/11 自带 WebView2 运行时，无需额外依赖。
