# v0.1.0 · 需求规格

本文档是需求拷问会话的定稿。术语的唯一依据是根目录 [CONTEXT.md](../../CONTEXT.md)，本文只引用不重复定义。

## 1. 产品定位

低落日记是一个开源、本地运行的单用户情绪陪伴桌面应用。用户记录低落时刻，Agent 读懂情绪、主动倾听、持续陪伴。产品初衷来自 README：我们习惯用各种事情逃避低落情绪，这个项目用来**面对**它。

主叙事（见 ADR-0004）：**Agent 为魂，笔记为形**；记录永不因 Agent 失能而不可用。

## 2. 用户与形态

- 目标用户：先做给自己用，以开源形式发布，用户下载安装到本地使用。
- 无账号、无服务器、无多用户（ADR-0001）。
- 形态：Windows 桌面应用（双击运行），后续版本考虑 macOS/Linux。

## 3. 功能需求（v0.1.0 范围）

### FR-1 记录
- 支持自由书写文字，可附加图片（第一版仅此两种输入）。
- 记录动作永远可用：未配置模型、模型调用失败（降级模式）时记录不受阻。
- 日记按时间倒序可查。

### FR-2 分析
- Agent 在后台把日记条目分析成心情记录：情绪标签（可多个）+ 强度（1-10）+ 一句话摘要，全部中文。
- 分析产物与原条目关联，可追溯由哪个模型产出。

### FR-3 唤醒对话
- 用户主动唤醒 Agent；唤醒后 Agent 先查看最近日记与心情记录了解状态，再开始对话。
- 对话为流式输出；历史会话可回看。

### FR-4 危机应对
- 判定：关键词初筛（可离线）+ LLM 复判，两级机制。
- 应对：先共情接住情绪，再温和提供求助资源（预置热线，用户可按所在地区补充）；不评判、不中断对话、不上报第三方（ADR-0003）。
- 危机应对同时作用于分析链路与对话链路。

### FR-5 降级模式
- 触发：未配置模型，或模型调用失败。
- 行为：日记功能完整可用；分析、对话暂停；界面明确告知降级状态。
- 恢复：配置好模型或调用恢复后自动回到完整模式。

### FR-6 模型配置
- 只支持 OpenAI 兼容协议：Base URL + API Key + 模型名三件套（ADR-0002）；端点可以是裸模型，也可以是带人设/工具的 agent 服务，协议上无差别。
- 配置即换，不做连通性测试按钮，不多套配置；历史心情记录与性格画像保留。
- 日记原文直发用户所配模型，不做脱敏。

## 4. 非功能需求

- **隐私**：所有数据（条目、图片、心情记录、对话、配置）只存本机用户数据目录；无任何自有服务端（ADR-0001）。
- **开源**：代码可审计，危机话术与判定逻辑对社区透明。
- **语言**：界面、文档、提示词、分析产物全部中文。
- **可测**：危机判定的关键词初筛必须可离线测试，不依赖 LLM。

## 5. 明确不做（第二波及以后）

定时关怀、信号触发、人格模板、托盘常驻与系统通知、回顾可视化（情绪日历/趋势/回顾报告）、设置界面、密钥加密存储、语音输入。
