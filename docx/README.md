# 低落日记 · 版本开发文档

## 文档体系

- `docx/`：版本开发文档，**一版一夹，目录名即版本号**。
- `docs/adr/`：跨版本架构决策记录，不随版本走。
- `front_design/`：前端设计方案（布局、视觉、组件、交互流），跨版本。
- 开发任何模块前的阅读顺序：`AGENTS.md` → `CONTEXT.md`（术语表）→ 当前版本 `README.md` → 对应模块文档。

## 版本路线图

| 版本 | 主题 | 范围 | 状态 |
|---|---|---|---|
| v0.1.0 | MVP 陪伴闭环 | 记录 → 分析 → 唤醒对话（含危机应对、降级模式） | 已完成（便携版已被 v0.1.1 取代） |
| v0.1.1 | 桌面壳升级 | Tauri 2 迁移、轮次03 视觉落地 | 已完成 |
| v0.1.2 | 修复与体验优化 | 结构原子化重构、用户反馈问题修复（+10/11/12 补充修复） | 已完成（已发布；补充修复 10/11/12 已全部重打包） |
| v0.2.0 | 主动陪伴 | 可选开启（默认关闭）；三档「冷淡 / 正常 / 关心」按频率在 09:00–22:30 内随机开口、消息落进最近活跃会话；人格模板（默认 + 自定义 `soul.md`）；设置整理（模型 / 陪伴 / 人格）；托盘常驻与系统通知；会话删除（只删这次对话、物理删除不可恢复） | 已发布（2026-10-13） |
| v0.3.0 | 陪伴感深化 | 日记回应（写完后条目下方留一两句留言，「聊聊」跳会话继续聊）；信号触发（连续低落 / 强度突变时不等频率轮到、带着近几天状态提前开口）；记忆按日期定位修复 | 已发布（2026-10-13） |

版本范围与 `AGENTS.md` 的 MVP 边界保持一致；变更时两处同步改。

回顾可视化、密钥加密存储（原 v0.3.0 主题「回望与完善」）顺延至后续版本，不指定版本号。
