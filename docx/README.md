# 低落日记 · 版本开发文档

## 文档体系

- `docx/`：版本开发文档，**一版一夹，目录名即版本号**。
- `docs/adr/`：跨版本架构决策记录，不随版本走。
- `front_design/`：前端设计方案（布局、视觉、组件、交互流），跨版本。
- 开发任何模块前的阅读顺序：`AGENTS.md` → `CONTEXT.md`（术语表）→ 当前版本 `README.md` → 对应模块文档。

## 版本路线图

| 版本 | 主题 | 范围 | 状态 |
|---|---|---|---|
| v0.1.0 | MVP 陪伴闭环 | 记录 → 分析 → 唤醒对话（含危机应对、降级模式） | 开发中 |
| v0.1.1 | 桌面壳升级 | Tauri 2 迁移、轮次03 视觉落地 | 已完成 |
| v0.1.2 | 修复与体验优化 | 结构原子化重构、用户反馈问题修复 | 进行中 |
| v0.2.0 | 主动陪伴 | 定时关怀、信号触发、人格模板、托盘常驻与系统通知 | 未开始 |
| v0.3.0 | 回望与完善 | 回顾可视化、设置界面、密钥加密存储 | 未开始 |

版本范围与 `AGENTS.md` 的 MVP 边界保持一致；变更时两处同步改。
