# v0.2.0 · 主动陪伴

> 状态：已发布（2026-10-13，Release v0.2.0 上线并挂安装包）；00~05 已完成，06 覆盖安装 / 干净机器验证待用户装包后回填。

## 需求来源

用户口述（2026-10-12，本条保留原始口径以便追溯）：

1. 新增删除功能：用户可以选择删除和模型的某次对话（全部删了，不备份，不保留）。
2. 新增陪伴功能：可在设置中开启或关闭，关闭后同现在的调用模式（用户问了模型再回答）；开启后不用用户手动打开窗口，Agent 自己开口、自己打开。三个档位「冷淡 / 正常 / 关心」主要对应三种频率，开启后像朋友一样基于用户的信息主动聊天。
3. 人格：默认人格就是现在使用的；新增用户自定义（默认不开启，需在设置中开启；有内容用用户的，没内容用默认）。人格定义在 `soul.md`；设置里是一个输入框，主题与风格与软件一致。更改后立即生效——每个发送前检查一遍是否有自定义内容（纯程序完成）。
4. 整理设置：新增的两项都在设置里调整。侧边栏分三页——模型（api、url、温度、思考强度）、陪伴（默认关闭，开启后选档位）、人格（默认关闭，开启后展示 `soul.md` 内容、可点击编辑；默认人格在 prompts 文件夹，不放进 `soul.md`）。

## 版本目标

让 Agent 像朋友一样主动陪伴：用户开启后，Agent 在一天里自己找时机开口，消息落进最近活跃会话里连续聊；人格可由用户自定义；设置按「模型 / 陪伴 / 人格」三页整理；单次对话可彻底删除。

**设计总尺子**：这个产品是让人写负面情绪的，陪伴要给足、尽量自然——频率给够，靠"随机时机 + 让路 + 不回不追"保证不烦人。

## 范围

**做**：00-术语与文档同步、01-托盘常驻与系统通知、02-设置整理、03-会话删除、04-人格模板、05-主动陪伴引擎、06-打包发布。

**不做**：信号触发（术语保留、本轮不做）；事件触发（该形式取消，与"频率驱动"不符）；会话内追问（术语保留，本轮不作为独立功能——追问由对话内既有口吻承担）；回顾可视化与密钥加密存储（v0.3.0）；"清空全部会话"（需要了再加）；删除会话时联动删除长期记忆。

## 关键决策（已定 2026-10-12）

| 决策项 | 定论 |
|---|---|
| 主动陪伴开关 | 可选功能，**默认关闭**；关闭时与现状完全一致（用户唤醒后才回应） |
| 档位与频率 | 三档「冷淡 / 正常 / 关心」：下次开口 = 上次开口时刻 + 档位间隔区间内的随机值（4~6h / 2~3h / 1~2h）；当日上限 3 / 6 / 12 次；计时细节见 [05 表一](./modules/05-主动陪伴引擎.md)（基准值，实机微调） |
| 开口时机与让路 | 巡检窗口 09:00–22:30（窗口外一律不开口）；两次开口最小间隔 ≥45 分钟（兜底）；「正在写日记 / 正在对话中」= 相应界面 5 分钟内有动作、自动过期；进程启动 10 分钟内让路（判据见 [05 表二](./modules/05-主动陪伴引擎.md)） |
| 未回退避 | 一次开口后不连续追加第二条，下一周期照常开口（新话题）；连续 3 次开口均未被回 → 当日停止、次日恢复；用户在任何会话发消息即清零（打开通知不算）（见 [05 表四](./modules/05-主动陪伴引擎.md)） |
| 开口落点 | 追加到**最近活跃会话**（术语表已定义）；一条会话都没有时才新建；生成开始取候选、落库前校验存在性 |
| 在途处置 | 生成完成时按序判断：开关已关 → 丢弃；目标会话已删 → 丢弃（不改投不新建）；用户正值活跃或已越窗 → 落库不弹通知；其余 → 落库，窗口不在前台才发通知（见 [05 表三](./modules/05-主动陪伴引擎.md)） |
| 开口内容 | 与唤醒同源：最近的日记与心情 + 长期记忆 + 当前时间，再叠人格；每次一两句，像微信 |
| 是否开口由谁判 | **程序判定**（窗口 + 间隔 + 当日次数 + 让路 + 退避）；模型只负责"说什么"——"一次生成任务"复用现有主智能体链路，可能含工具调用与空回复兜底的多次模型请求 |
| 会话删除 | 只删这次对话本身——`messages` + `sessions` + 图状态 checkpoint 三处物理删除，不备份、不可恢复；**长期记忆不动**，无任何连带；删除成功后旧任务不得再写入或恢复该会话（见 [03](./modules/03-会话删除.md)） |
| 人格模板 | 自定义内容只能替换 system prompt 的**风格层**（角色设定 + 怎么说话）；系统注入的数据段与「工具与边界」固定保留（代码保证，见 [04](./modules/04-人格模板.md)）；自定义内容存数据目录 `soul.md`；每条用户消息发送前与每次主动开口前各读一次；上限 2000 字；空内容或开关关闭则回退默认人格（随包，在 `agent/prompts/`） |
| 降级模式 | 本版只改主动开口的失败策略：未配置模型或调用失败 → 本次跳过，不补发、不攒；记录与既有链路不变，日整合的分阶段降级沿用现状 |
| 托盘与自启 | 关窗收进托盘、不退进程；托盘菜单含"退出"（退出时调度与后端 sidecar 一并结束）；单实例；支持开机自启（默认关闭） |
