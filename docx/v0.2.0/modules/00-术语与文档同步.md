## 背景

v0.2.0 范围收口（2026-10-12）后，「主动陪伴 / 档位 / 定时关怀 / 人格模板」几处术语与路线图口径必须与最终决策一致。术语表是代码命名的依据，先行对齐再动代码。

## 方案要点

- 档位命名统一「冷淡 / 正常 / 关心」；原「冷淡 / 关怀 / 热情」作废——"关怀"已是术语（主动关怀），档位再叫"关怀"会撞词。
- 「事件触发」形式取消（与"频率驱动"不符），从术语表移除。
- 「定时关怀」定义改为"按主动陪伴档位决定的频率、在一天里随机时机主动开口"，不再有用户设定的钟点。
- 「主动陪伴」补全语义：可选功能、默认关闭、进程运行期间、未开启时等于现状（用户唤醒后才回应）。
- 「人格模板」定义改写为"默认人格（随包，在 `agent/prompts/`）+ 用户自定义人格（数据目录 `soul.md`）"。
- 路线图 v0.2.0 行、进度树、当前开发版本、v0.3.0 行（去「设置界面」）与 `AGENTS.md` 的 MVP 边界行同步。
- 归档（`docx/v0.1.0/`、`docx/v0.1.2/`、`docs/release-*.md`）按归档规则不回写，历史口径保持原样。
