## 背景

本版新增的陪伴开关、档位、人格自定义都要有落点，而现有设置只有一个模型配置对话框。整理为侧边栏三页，让三件事各归其位。

## 方案要点

侧边栏三页：

- **模型**：沿用现有字段与行为（Base URL / API Key / 模型名 / 温度 / 思考强度），不增删不改语义。
- **陪伴**：开关（**默认关闭**）；开启后出现档位三选一「冷淡 / 正常 / 关心」。
- **人格**：开关（**默认关闭**）；开启后展示编辑框。

**人格页编辑语义（与 04 配套，避免歧义）**

| 项 | 规则 |
|---|---|
| 编辑框内容 | 只承载**自定义内容**（`soul.md` 原文）；为空 = 未自定义，运行时用默认人格 |
| 默认人格 | 提供"查看默认人格"只读预览，不填进编辑框、不可保存进 `soul.md` |
| 保存动作 | 手动点"保存"（避免模型读到写到一半的文本）；成功有提示 |
| 计数口径 | 2000 字 = 去首尾空白后的字符数；纯空白视为空 |

- 设置项存 `settings` 表（沿用现有键值存取），陪伴开关、档位、人格开关各自独立。
- 文案与命名按 `CONTEXT.md`，禁用说法（"人设""推送"等）不得出现。
- 视觉细节先读 `front_design/`；不改既有模型页字段与行为。
