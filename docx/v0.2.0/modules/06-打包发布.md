## 方案要点

- 版本号多处同步（后端包版本 / 前端 `package.json` / Tauri 配置），避免界面与安装包显示不一致。
- 走既有链路：npm 构建 → 后端 PyInstaller sidecar → Tauri NSIS 安装包，产物在 `dist/`；本版**只交付安装包**（便携版自 v0.1.1 起已被取代，不再维护）。
- 本版新增托盘、通知、自启与常驻进程，都是打包态才暴露问题的项：覆盖升级**前先结束常驻进程**（避免文件占用）。
- Release 文案与附件；**推送到 GitHub 与创建/修改 Release 前必须征得用户同意**。
